## 연산자
숫자형 자료형을 가공하기 위한 연산자.
 - 덧셈 : +
 - 뺄셈 : -
 - 곱셈 : *
 - 나눗셈 : /
 - 나머지 : %
 - 제곱 : **
 - (나눗셈 후)몫 : //
-------------------------------------
## 연산자 우선순위
 계산기와 같은 우선순위를 가짐
  1. 제곱 연산자
  2. 곱셈, 나눗셈, 나머지, 몫 연산자
  3. 덧셈, 뺄셈 연산자
  4. 괄호()를 통해 연산자 우선순위를 변경할 수 있음.


```python
a = 10
b = 5

result=a+b      # a(10) + b(5)의 값을 result에 저장한다.
print(result)

result = a - b      # a(10) - b(5)의 값을 result에 저장한다.
print(result)

result = a * b      # a(10) X b(5)의 값을 result에 저장한다.
print(result)

# 다른 연산자는 결과 값이 동일한 자료형으로 나오는데,
# 나머지 연산자는 무조건, 실수형으로 나옵니다.
result = a / b      # a(10) / b(5)의 값을 result에 저장한다.
print(result)

result = a % b      # a(10) % b(5)의 값을 result에 저장한다.
print(result)       # 10 / 5 = 몫 : 2, 나머지 : 0
print(10 % 7)       # 10 / 7 = 몫 : 1, 나머지 : 3

result = a**b       # a(10) ** b(5)의 값을 result에 저장한다.
print(result)

result = a//b       # a(10) // b(5)의 값을 result에 저장한다.
print(result)       # 10 / 5 = 몫 : 2, 나머지 : 0

result = 2 + 3 * 4    # 14
print(result)

result = (2 + 3) * 4  # 20
print(result)
```

## 문자열 슬라이싱

 - 변수명[첫번째항목:마지막항목+1]

 - 마지막 항목을 공백으로 놓으면, 문자열 끝까지 추출.


```python
text = "python is good"
```

## 문자열 포맷 코드
문자열 포맷 코드 헷갈리면 무조건 %s 사용!!
 - %s : 문자열(string)
 - %c : 문자 1개(character)
 - %d : 정수(integer)
 - %f : 실수(Floating point)
 - %o : 8진수
 - %x : 16진수


```python
# 문자열 포맷 코드(%d)에 숫자를 바로 대입하는 방법.
print("사과 %d 개가 있습니다." % 3)

# 문자열 포맷 코드(%s)에 문자열을 바로 대입하는 방법.
print("제 이름은 %s 입니다." % "유연휘")

number = 5
# 문자열 포맷 코드에 변수를 대입하는 방법.
print("사과 %d 개가 있습니다." % number)

# 2개 이상의 문자열 포맷 코드 % (a, b)의 형식으로 사용
fruit = "사과"
number = 5
print("저는 %d개의 %s가 있습니다." %(number, fruit))

# %d를 %s로 바꾸어도 상관없음.
print("저는 %s개의 %s가 있습니다." %(number, fruit))
```

## 리스트 인덱싱
리스트도 문자열과 유사하게 인덱싱 및 슬라이싱이 가능하다.

단, 문자열이나, 리스트 내부의 리스트도 하나의 요소로 취급한다.
 - a = [1, "문자열", -0.5, '안녕']
 - a[0] = 1
 - a[1] = "문자열"
 - a[2] = -0.5

## 딕셔너리 관련 함수
 - keys() : key 리스트 만들기
 - values() : value 리스트 만들기
 - items() : key, value 쌍 리스트 얻기(튜플값)
 - clear() : key: value 쌍 모두 지우기
 - get() : key값을 통해 value값 얻기
 - in : key가 딕셔너리에 있는지 찾아보기(true, false)


```python
dic = {'사과': 'apple', '바나나': 'banana', '메론': 'melon'}

print(dic.values())         # value 리스트
print(dic.items())          # (key, vlaue) 리스트

print(dic.get('바나나'))    # '바나나'의 value 없기
print('사과' in dic)        # '사과' key가 딕셔너리에 있는지 조사
print('수박' in dic)        # '수박' key가 딕셔너리에 있는지 조사

dic.clear()                 # 딕셔너리 초기화
print(dic)
```

## 1. 고양이 사진 API (The Cat API)

### 소개
- 전 세계 고양이 사진을 무료로 제공하는 공개 API입니다.
- 랜덤 고양이 사진이나, 특정 품종의 고양이 사진도 가져올 수 있습니다.

### 공식 문서
- https://docs.thecatapi.com/

### 주요 활용 방법
| 항목 | 내용 |
|:-----|:----|
| URL | `https://api.thecatapi.com/v1/images/search` |
| 요청 방식 | GET |
| 인증키 필요 여부 | 기본 사용은 필요 없음 |
| 반환 데이터 | 고양이 이미지 URL 리스트 (JSON)

### 대표 예제 코드
```python
import requests
from IPython.display import Image, display

url = "https://api.thecatapi.com/v1/images/search"
response = requests.get(url)
data = response.json()
cat_url = data[0]['url']

print("오늘의 고양이 사진:")
display(Image(url=cat_url))
```

### 반환되는 JSON 구조 예시

## 2. 날씨 정보 API (Open-Meteo API)

### 소개
- 위치(위도, 경도)를 기준으로 현재 날씨, 예보, 기온, 풍속 등 다양한 날씨 정보를 제공합니다.
- 무료이며, 인증키 없이 바로 사용할 수 있습니다.

### 공식 문서
- https://open-meteo.com/en/docs

### 주요 활용 방법
| 항목 | 내용 |
|:-----|:----|
| URL | `https://api.open-meteo.com/v1/forecast` |
| 요청 방식 | GET |
| 인증키 필요 여부 | 필요 없음 |
| 반환 데이터 | 날씨 정보 (JSON)

### 대표 예제 코드
```python
import requests
from datetime import datetime

latitude = 37.5665
longitude = 126.9780
today = datetime.utcnow().date()

url = (
    f"https://api.open-meteo.com/v1/forecast?"
    f"latitude={latitude}&longitude={longitude}"
    f"&daily=temperature_2m_max,temperature_2m_min&timezone=Asia%2FSeoul"
)
response = requests.get(url)
data = response.json()

dates = data['daily']['time']
max_temps = data['daily']['temperature_2m_max']
min_temps = data['daily']['temperature_2m_min']

for i, date in enumerate(dates):
    if date == str(today):
        print(f"오늘({today}) 서울 날씨")
        print(f"- 최고 기온: {max_temps[i]}°C")
        print(f"- 최저 기온: {min_temps[i]}°C")
```

## 3. 명언 제공 API (ZenQuotes API)

### 소개
- 전 세계 다양한 명언을 랜덤하게 제공합니다.
- 별도의 회원가입 없이 사용할 수 있습니다.

### 공식 문서
- https://zenquotes.io/api

### 주요 활용 방법
| 항목 | 내용 |
|:-----|:----|
| URL | `https://zenquotes.io/api/random` |
| 요청 방식 | GET |
| 인증키 필요 여부 | 필요 없음 (하루 50회 제한) |
| 반환 데이터 | 명언 리스트 (JSON)

### 대표 예제 코드
```python
import requests

url = "https://zenquotes.io/api/random"

data = response.json()

quote = data[0]['q']
author = data[0]['a']

print("오늘의 명언:")
print(f'"{quote}" — {author}')
```

### 인증키 때문에 추후에 많은 금액 발생 


```python


import requests
import json
import random 

apikey = '472C2678859F235C5AC0B162E969FEF9'

player = input('사용자: ')

while player != "그만": # 추가: '그만'이라고 칠 때까지 무한 반복

    # --- [추가] 사용자가 입력한 단어가 사전에 있는지 확인 ---
    check_url = f'https://opendict.korean.go.kr/api/search?key={apikey}&target_type=search&req_type=json&q={player}'
    check_res = requests.get(check_url) # 인터넷에 물어보기
    check_data = json.loads(check_res.text) # 결과를 읽기 쉽게 바꾸기

    # 검색 결과(total)가 0이면 없는 단어임
    if check_data['channel']['total'] == 0:
        print(f"'{player}'(은)는 사전에 없는 단어입니다! 다시 입력하세요.")
        player = input('사용자: ')
        continue # 다시 루프 처음으로 돌아가서 입력을 받음



     # 사용자가 입력한 단어의 마지막 글자 가져오기
    query = player[-1]

    # 마지막 글자로 시작하는 단어를 찾기 위한 주소
    url = f'https://opendict.korean.go.kr/api/search?certkey_no=8916&key={apikey}&target_type=search&req_type=json&part=word&sort=popular&start=1&num=100&pos=1&q={query}'
    print(url) # 확인용으로 주소 출력

    response = requests.get(url) # 인터넷에 다시 물어보기
    words = json.loads(response.text) # 결과 읽기 쉽게 바꾸기

    list_a = [] # 단어들을 담을 빈 리스트 만들기

    items = words.get('channel', {}).get('item', [])

    for i in range(10):
        # 단어의 첫 글자가 우리가 원하는 글자랑 같으면
        # 품사(pos)와 단어(word)는 모두 'sense' 안에 있습니다.
        target_info = items[i]['sense']
        
        # 조건: 첫 글자가 query와 같고 품사가 '명사'인 경우
        if target_info['word'][0] == query and target_info['pos'] == '명사':
```
