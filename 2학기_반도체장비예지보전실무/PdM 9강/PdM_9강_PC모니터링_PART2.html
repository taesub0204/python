1. 컴퓨터 활동과 자원 사용량

1.1. 활동별 자원 사용 패턴

컴퓨터는 수행하는 작업에 따라 CPU, 메모리, 디스크, 네트워크 자원을 다르게 사용한다. 웹페이지를 열 때는 데이터를 수신하고 화면을 구성하며, 동영상을 재생할 때는 영상 데이터를 수신하고 디코딩한다.

네 가지 활동을 수행하고, 활동별 사용량을 수집한다.

활동 이름수행 작업
idle다른 작업을 하지 않고 대기
web여러 웹페이지 탐색
video유튜브 영상 재생
python파이썬 반복 연산 실행

각 활동을 40초 동안, 2초 간격으로 측정한다.

1.2. 수집할 데이터

컬럼의미
time측정 시각
activity수행한 활동 이름
cpuCPU 사용률(%)
memory메모리 사용률(%)
disk_read_mb_s초당 디스크 읽기량(코드의 명칭은 MB/s, 실제 계산 단위는 MiB/s)
net_recv_mb_s초당 네트워크 수신량(실제 계산 단위 MiB/s)

CPU·메모리는 사용률을 확인하고, 디스크·네트워크는 누적 전송량의 차이를 이용해 측정 구간의 초당 전송량을 계산한다.

2. PC 모니터링 데이터 수집하기

실습 01

PC 블랙박스 프로그램 만들기

collect.py 파일을 생성한다. 활동별로 자원 사용량을 측정하고 pc_data.csv로 저장한다.

collect.py · Python
import pandas as pd
import psutil
from datetime import datetime

activities = ["idle", "web", "video", "python"]
INTERVAL = 2
DURATION = 40
records = []

print("PC 모니터링을 시작합니다.")

for activity in activities:
    print(f"\n다음 활동: {activity}")
    input("준비되면 Enter를 누르세요.")

    psutil.cpu_percent(interval=None)
    prev_disk = psutil.disk_io_counters()
    prev_net = psutil.net_io_counters()

    for i in range(DURATION // INTERVAL):
        cpu = psutil.cpu_percent(interval=INTERVAL)
        memory = psutil.virtual_memory().percent
        disk = psutil.disk_io_counters()
        net = psutil.net_io_counters()

        disk_read = (
            (disk.read_bytes - prev_disk.read_bytes)
            / INTERVAL / 1024**2
        )
        net_recv = (
            (net.bytes_recv - prev_net.bytes_recv)
            / INTERVAL / 1024**2
        )

        records.append({
            "time": datetime.now().isoformat(timespec="seconds"),
            "activity": activity,
            "cpu": cpu,
            "memory": memory,
            "disk_read_mb_s": disk_read,
            "net_recv_mb_s": net_recv
        })

        prev_disk = disk
        prev_net = net

        print(
            f"{activity:7s} | "
            f"CPU {cpu:5.1f}% | "
            f"RAM {memory:5.1f}%"
        )

df = pd.DataFrame(records)
df.to_csv("pc_data.csv", index=False, encoding="utf-8-sig")

print("\n수집 완료!")
print(df.groupby("activity")[["cpu", "memory"]].mean())

코드 설명 ① 측정 조건

코드설명
activities측정할 네 가지 활동을 순서대로 저장한다.
INTERVAL = 2측정 간격을 2초로 설정한다.
DURATION = 40각 활동의 측정 시간을 40초로 설정한다.
DURATION // INTERVAL활동별 반복 횟수를 계산한다(20번).
input()Enter 입력 전까지 다음 활동을 시작하지 않는다.

코드 설명 ② 시스템 자원 가져오기

코드설명
psutil.cpu_percent()CPU 사용률을 측정한다.
psutil.virtual_memory().percent메모리 사용률을 가져온다.
psutil.disk_io_counters()디스크 읽기·쓰기 누적값을 가져온다.
psutil.net_io_counters()네트워크 송수신 누적값을 가져온다.

초당 전송량은 (현재 누적값 − 이전 누적값) ÷ 측정 간격으로 계산한다. 바이트를 1024**2로 나눠 MiB 단위로 변환한다.

코드 설명 ③ 데이터 저장

코드설명
records.append({ ... })각 측정 결과를 딕셔너리로 만들어 리스트에 추가한다.
pd.DataFrame(records)저장된 측정값을 데이터프레임으로 변환한다.
df.to_csv(...)데이터를 CSV 파일로 저장한다.
index=False데이터프레임의 인덱스를 CSV에 저장하지 않는다.
encoding="utf-8-sig"Excel 등에서 한글을 읽기 편하도록 BOM이 포함된 UTF-8로 저장한다.

들여쓰기 주의: records.append()와 누적값 갱신, 화면 출력 코드는 안쪽 for i in ... 반복문 내부에 있어야 한다. 반복문 바깥에 두면 활동마다 마지막 값 하나만 저장될 수 있다.

3. 네 가지 활동 수행하기

실습 02

활동별 측정 실행

collect.py를 실행하고, 화면에 표시되는 활동에 맞춰 작업을 수행한다. 각 활동의 준비가 끝나면 Enter를 눌러 측정을 시작한다.

활동수행 방법
idle다른 작업을 하지 않고 대기한다.
web뉴스·검색 사이트 등의 웹페이지를 탐색한다.
video유튜브에서 1080p 동영상을 재생한다.
python별도로 연 명령 창에서 CPU 부하 프로그램을 실행한다.

CPU 부하 프로그램

collect.py와 같은 폴더에 cpu_load.py 파일을 생성한다.

cpu_load.py · Python
import time

end_time = time.perf_counter() + 20

while time.perf_counter() < end_time:
    total = 0

    for i in range(100_000):
        total += i * i

print("CPU 부하 테스트 완료")

time.perf_counter()로 경과 시간을 확인하면서 약 20초 동안 계산을 반복한다.

명령 창 열기 및 실행 순서

  1. VS Code에서 collect.py를 실행한다.
  2. 파일 탐색기에서 cpu_load.py가 저장된 폴더를 연다.
  3. 폴더의 빈 공간을 마우스 오른쪽 버튼으로 클릭한 뒤 ‘터미널에서 열기’를 선택한다. Windows 설정에 따라 메뉴 이름이나 실행되는 셸이 다를 수 있다.
  4. idle, web, video 활동을 순서대로 수행한다.
  5. python 활동 메시지가 나오면 VS Code 터미널에서 Enter를 누른다.
  6. 별도로 열린 터미널에서 아래 명령을 실행한다.
  7. 수집 완료 메시지가 나오면 pc_data.csv가 생성되었는지 확인한다.
별도로 열린 터미널 · 명령어
python cpu_load.py

‘터미널에서 열기’가 보이지 않는다면: 파일 탐색기에서 해당 폴더를 연 상태로 주소 표시줄에 cmd를 입력하고 Enter를 누른다. 현재 폴더에서 명령 프롬프트가 열린다. 폴더가 아닌 .py 파일 자체를 오른쪽 클릭하는 것이 아니다.

안전: CPU 부하 실행 중 발열이 심하거나 PC가 지나치게 느려지면 실행을 중단한다. 전체 CPU 사용률이 100%에 도달하지 않아도 정상적인 결과일 수 있다.

4. 활동별 CPU·메모리 사용률 시각화하기

실습 03

활동별 그래프 출력

visualize.py 파일을 생성한다. CSV 데이터를 활동별로 나누고, 네 개의 그래프로 나타낸다.

visualize.py · Python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("pc_data.csv")
fig, axes = plt.subplots(4, 1, figsize=(11, 9))

for ax, (activity, data) in zip(
    axes, df.groupby("activity", sort=False)
):
    ax.plot(range(len(data)), data["cpu"], label="CPU (%)")
    ax.plot(range(len(data)), data["memory"], label="Memory (%)")
    ax.set_title(activity)
    ax.set_ylim(0, 100)
    ax.set_ylabel("Usage (%)")
    ax.legend()
    ax.grid(alpha=0.3)

axes[-1].set_xlabel("Sample number (2 seconds each)")
plt.tight_layout()
plt.show()

코드 설명

코드설명
pd.read_csv()CSV 파일을 데이터프레임으로 불러온다.
plt.subplots(4, 1)세로로 배치한 그래프 네 개를 만든다.
df.groupby("activity")활동 이름을 기준으로 데이터를 그룹화한다.
zip()그래프 객체와 활동별 데이터를 짝지어 반복한다.
ax.plot()CPU와 메모리 사용률을 선 그래프로 그린다.
ax.legend()그래프의 범례를 표시한다.
plt.tight_layout()그래프 요소가 겹치지 않도록 간격을 조정한다.

그래프에 선이 보이지 않는 경우: 활동마다 측정값이 하나씩만 저장되지 않았는지 CSV를 확인한다. 데이터가 한 점이면 연결할 선이 없다.

5. 활동별 자원 사용량 비교하기

실습 04

활동별 통계값 확인

visualize.py의 그래프 표시 코드 뒤에 추가한다. 활동별 평균, 최댓값, 표준편차를 비교한다.

visualize.py에 추가 · Python
summary = df.groupby("activity").agg(
    cpu_mean=("cpu", "mean"),
    cpu_max=("cpu", "max"),
    cpu_std=("cpu", "std"),
    memory_mean=("memory", "mean"),
    disk_read_mean=("disk_read_mb_s", "mean"),
    net_recv_mean=("net_recv_mb_s", "mean")
)

print(summary.round(2))

코드 설명

코드설명
.agg()여러 집계 연산을 한 번에 수행한다.
mean평균을 계산한다.
max최댓값을 계산한다.
std표준편차를 계산한다.
.round(2)출력값을 소수점 둘째 자리까지 반올림한다.

평균은 전반적인 자원 사용 수준을, 표준편차는 측정 구간 내 값의 변동 정도를 나타낸다.

6. PART 02 정리

활동 수행→측정
psutil→CSV 저장→시각화→통계 비교

컴퓨터의 작업에 따라 자원 사용량이 달라질 수 있다. 다만 같은 작업에서도 PC 환경과 실행 조건에 따라 패턴이 달라질 수 있다.

수집한 데이터로 시도해볼 수 있는 작업

활용 예시내용
사용 패턴 분석CPU·메모리·디스크·네트워크 변화를 비교한다.
특성공학평균·최댓값·표준편차·변화량 등의 특성을 만든다.
작업 유형 분류자원 사용 패턴으로 작업 종류를 추정하는 모델을 실험한다.
미래 사용률 예측과거 CPU 사용률을 이용해 이후의 사용률을 예측한다.
이상 패턴 탐지평소와 다른 자원 사용 상태를 찾아본다.
모니터링 대시보드자원 사용량을 실시간으로 보여주는 화면을 만든다.

이러한 실험에는 목적에 맞는 추가 데이터 수집과 전처리가 필요할 수 있다.
