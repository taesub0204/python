PART 01.
내 컴퓨터의 CPU 사용률 확인하기

컴퓨터 자원 사용량을 직접 측정하고 시계열 그래프로 나타낸다.

예상 20~25분실습 3개질문 3개로컬 Python
학습 목표
CPU·메모리 사용률을 확인하고, CPU 사용률을 반복 측정하여 리스트에 저장한 뒤 선 그래프로 표현한다.

1. 내 컴퓨터도 모니터링할 수 있을까?

1.1. PC 모니터링

PC 모니터링은 컴퓨터의 자원 사용 상태를 확인하는 작업이다.

대표적인 모니터링 대상은 다음과 같다.

항목의미
CPU프로그램의 명령을 처리하는 장치
메모리(RAM)실행 중인 프로그램과 데이터를 임시로 저장하는 공간
디스크프로그램과 데이터를 저장하는 장치
네트워크다른 컴퓨터와 데이터를 주고받는 통신 기능

컴퓨터에서 실행하는 작업에 따라 자원 사용량이 달라진다. 이러한 값을 일정한 간격으로 기록하면 시계열 데이터를 만들 수 있다.

1.2. 작업 관리자에서 확인하기

Windows 작업 관리자의 성능 탭에서 CPU와 메모리 사용 상태를 확인한다.

  1. Ctrl + Shift + Esc로 작업 관리자를 실행한다.
  2. 성능 → CPU를 선택하여 CPU 사용률을 확인한다.
  3. 성능 → 메모리를 선택하여 메모리 사용량을 확인한다.

2. CPU와 메모리 사용률 측정하기

실습 01

CPU·메모리 사용률 출력

psutil 라이브러리를 사용하여 현재 PC의 CPU와 메모리 사용률을 측정한다.

practice01.py · Python
import psutil

cpu = psutil.cpu_percent(interval=1)
memory = psutil.virtual_memory().percent

print("CPU 사용률:", cpu, "%")
print("메모리 사용률:", memory, "%")

코드 설명

코드설명
psutil.cpu_percent(interval=1)1초 동안 CPU 사용률을 측정한다.
psutil.virtual_memory()메모리 사용 정보를 가져온다.
.percent메모리 사용률을 백분율 값으로 가져온다.

cpu와 memory에는 각각 실수(float) 형태의 사용률이 저장된다.

3. CPU 사용률 반복 측정 및 저장하기

CPU 사용률은 실행 중인 작업에 따라 계속 변한다. 일정한 간격으로 측정한 값을 리스트에 저장하면 시간에 따른 변화를 확인할 수 있다.

실습 02

CPU 사용률 20번 측정하기

practice02.py · Python
import psutil

cpu_list = []

for i in range(20):
    cpu = psutil.cpu_percent(interval=1)

    cpu_list.append(cpu)

    print(f"{i+1}번째 측정: {cpu:.1f}%")

print(cpu_list)

코드 설명

코드설명
cpu_list = []측정값을 저장할 빈 리스트를 생성한다.
range(20)측정 과정을 20번 반복한다.
cpu_list.append(cpu)측정한 CPU 사용률을 리스트에 추가한다.
{cpu:.1f}CPU 사용률을 소수점 첫째 자리까지 표시한다.

4. CPU 사용률 시각화하기

실습 03

CPU 사용률 그래프

앞에서 만든 리스트를 matplotlib으로 시각화한다.

실습 02 코드 아래에 다음 코드를 추가한다.

practice02.py에 추가 · Python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 4))

plt.plot(cpu_list)

plt.title("CPU Usage")
plt.xlabel("Time (seconds)")
plt.ylabel("CPU Usage (%)")

plt.ylim(0, 100)
plt.grid()

plt.show()

코드 설명

코드설명
plt.figure(figsize=(10, 4))그래프 크기를 설정한다.
plt.plot(cpu_list)CPU 측정값을 선 그래프로 그린다.
plt.xlabel() / plt.ylabel()x축과 y축의 이름을 설정한다.
plt.ylim(0, 100)y축 범위를 0~100으로 설정한다.
plt.grid()그래프에 격자를 표시한다.
plt.show()그래프를 출력한다.

1초 간격으로 수집한 데이터이므로 측정 순서를 시간 흐름에 대응시켜 볼 수 있다. 첫 측정값의 x좌표는 0이다.
