CHAPTER 01

프로젝트 소개

1. 프로젝트 개요

반도체 제조현장에서는 웨이퍼를 여러 공정 사이로 운반하기 위해 자동화된 이송장치를 사용합니다.

이송장치에 이상이 발생하면 웨이퍼 운송이 지연되고, 생산 공정에도 영향을 줄 수 있습니다. 따라서 장비의 이상 징후를 조기에 발견하고 적절한 유지보수 시점을 판단하는 것이 중요합니다.

이번 프로젝트에서는 이송장치에서 수집한 센서 데이터를 분석하여 장비의 상태를 분류하는 머신러닝 모델을 구축합니다.

온도, 전류, 미세먼지 등의 센서 데이터를 이용하여 장비의 상태를 정상, 관심, 경고, 위험의 네 단계로 분류하고, 특성공학과 모델 개선 실험을 수행합니다.

2. 웨이퍼 이송장치란?

반도체 제조공정에서는 웨이퍼를 담은 용기 등을 여러 공정 장비 사이로 자동 운반합니다. 대표적인 이송장치로 OHT와 AGV가 있습니다.

OVERHEAD TRANSPORT

OHT · Overhead Hoist Transport

천장에 설치된 레일을 따라 이동하며 웨이퍼 운반 용기를 이송하는 장치입니다. 바닥 공간을 차지하지 않고 공정 장비 사이를 이동할 수 있습니다.

사진을 클릭하면 소개 영상을 볼 수 있습니다 ↗
AUTOMATED VEHICLE

AGV · Automated Guided Vehicle

바닥에서 정해진 경로나 유도 시스템을 따라 자동으로 이동하며 자재를 운반하는 무인 운반 장치입니다.

사진을 클릭하면 소개 영상을 볼 수 있습니다 ↗

두 장비는 모두 자재를 자동으로 운반하지만, 이동 방식과 장비 구조에는 차이가 있습니다. 이러한 차이가 센서 데이터의 특성에도 나타날 수 있습니다.

3. 열화와 예지보전

열화Degradation

장비를 구성하는 부품이나 재료의 성능이 사용 시간, 온도, 전기적 스트레스 등의 영향으로 점차 저하되는 현상입니다.

탄화Carbonization

재료가 높은 열 등에 노출되어 탄소가 풍부한 물질로 변하는 현상입니다. 절연재 등의 탄화는 절연 성능 저하와 고장 위험으로 이어질 수 있습니다.

예지보전Predictive Maintenance

장비의 상태와 운용 데이터를 분석하여 이상 징후나 고장 가능성을 파악하고, 적절한 유지보수 시점을 판단하는 방법입니다.

이번 프로젝트에서는 예지보전의 여러 방법 중 센서 데이터를 활용한 장비 상태 분류를 수행합니다.

미래의 정확한 고장 시점이나 잔여수명을 직접 예측하는 것이 아니라, 현재 측정된 데이터를 기반으로 장비의 상태를 분류하는 것이 목표입니다.

CHAPTER 02

프로젝트 데이터

1. 데이터 소개

이번 프로젝트에서는 AI허브에서 제공하는 제조현장 이송장치의 열화 예지보전 멀티모달 데이터를 활용합니다.

데이터는 산업 현장과 유사한 모사 환경에서 수집된 것으로, OHT와 AGV의 센서 측정값 및 장비 상태 정보 등을 포함합니다.

원본 데이터는 JSON 형식으로 제공되지만, 이번 실습에서는 분석에 집중할 수 있도록 표 형태로 변환한 CSV 파일을 사용합니다.

센서마다 측정하는 대상이 다르므로, 장비 상태에 따라 나타나는 변화도 서로 다를 수 있습니다.

예를 들어 온도가 상승한다고 해서 모든 전류 센서가 동일하게 증가하는 것은 아닙니다. 각 센서가 장비 상태와 어떤 관계를 가지는지는 데이터를 직접 분석하여 확인합니다.

3. 장비 상태 레이블

이번 데이터에서는 장비의 상태를 네 단계로 구분합니다.

레이블상태설명
0정상정상적으로 운용 가능한 상태
1관심이상 징후가 나타나 관찰이 필요한 상태
2경고이상이 진행되어 주의가 필요한 상태
3위험위험 수준에 도달하여 조치가 필요한 상태

상태 레이블은 데이터 구축 과정에서 통계적 이상 징후와 탄화 발생 시점 등을 고려하여 부여되었습니다.

이번 프로젝트에서는 state가 모델이 예측해야 하는 정답(Target)에 해당합니다.

학생들은 센서 데이터를 입력 특성(Feature)으로 사용하여 장비 상태를 예측하는 다중 클래스 분류 모델을 구축합니다.

4. 두 장비의 데이터를 비교하는 이유

AGV와 OHT는 동일한 종류의 센서 데이터를 가지고 있지만, 장비 구조와 운용 특성이 다릅니다. 따라서 같은 센서라도 측정값의 분포나 상태별 변화 양상이 다를 수 있습니다.

예를 들어 특정 온도 센서는 AGV에서 상태별 차이가 크게 나타나지만, OHT에서는 상대적으로 작은 차이를 보일 수 있습니다.

이러한 차이는 머신러닝 모델을 학습할 때에도 영향을 미칠 수 있습니다.
