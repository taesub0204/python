이번 미션에서 해결할 문제

미션 01에서는 AGV와 OHT의 센서 데이터를 탐색했습니다. 장비 상태에 따라 뚜렷한 변화를 보이는 센서도 있었고, 상태별 분포가 많이 겹치는 센서도 있었습니다.

장비 상태를 분류하는 데 모든 센서가 필요할까요?

센서 수를 줄이면서도 충분한 분류 성능을 유지할 수 있다면 데이터 수집과 처리 부담을 줄이고 모델을 더 단순하게 구성할 수 있습니다. 이번에는 특성공학(Feature Engineering) 중 특성 선택(Feature Selection)을 중심으로 탐구합니다.

특성공학의 주요 기법

기법 설명 예시
특성 선택 (Feature Selection) 기존 특성 중 필요한 것을 선택 11개 센서 특성 중 온도·전류 특성 3개만 사용
특성 변환 (Feature Transformation) 기존 특성의 값이나 표현 방식을 변경 표준화, 로그 변환
특성 생성 (Feature Creation) 기존 데이터로 새로운 특성을 생성 전류 합계, 열화상 온도와 내부 온도의 차이
특성 추출 (Feature Extraction) 여러 특성을 새로운 표현으로 압축 PCA를 이용한 차원 축소

이번에는 센서 특성 2개로 시작해 하나씩 추가하는 전진 선택(Forward Selection) 방식의 탐구를 진행합니다. 모든 후보 조합을 자동으로 평가하는 정식 전진 선택 알고리즘이 아니라, 학생이 직접 센서를 고르고 선택 이유와 결과를 비교하는 활동입니다.

# 장비별 분할 결과 저장
split_data = {}

for device, df in datasets.items():
    device_ids = sorted(df["device_id"].unique())

    if len(device_ids) != 5:
        raise ValueError(f"{device}: 장비 ID 5개를 예상했습니다.")

    val_df = df[df["device_id"].isin(val_ids)].copy()
    test_df = df[df["device_id"].isin(test_ids)].copy()

    split_data[device] = {
        "train": train_df,
        "val": val_df,
        "test": test_df
    }

    print(f"\n[{device}]")
    print("Train:", train_ids, len(train_df))
    print("Validation:", val_ids, len(val_df))
    print("Test:", test_ids, len(test_df))

2. 두 알고리즘을 같은 조건에서 준비하기

로지스틱 회귀는 StandardScaler로 표준화하고, 랜덤포레스트에는 원래 센서 값을 사용합니다. 학습 장비와 검증 장비, 입력 센서 조합은 동일하게 유지합니다.

PYTHON · 실습 코드
def make_model(algorithm):
    """알고리즘 이름에 맞는 새 모델을 생성합니다."""

    if algorithm == "LogisticRegression":
        # 학습 데이터로만 표준화 기준 계산
        return Pipeline([
            ("scaler", StandardScaler()),
            ("classifier", LogisticRegression(
                max_iter=1500,
                class_weight="balanced",
                random_state=42
            ))
        ])

    if algorithm == "RandomForest":
        # 결정트리 기반 모델은 표준화 없이 학습
        return RandomForestClassifier(
            n_estimators=100,
            class_weight="balanced",
            random_state=42,
            n_jobs=-1
        )

    raise ValueError(f"알 수 없는 알고리즘: {algorithm}")
설정 로지스틱 회귀 랜덤포레스트
특성 표준화 StandardScaler 적용하지 않음
클래스 가중치 balanced balanced
학습 반복/규모 max_iter=1500 n_estimators=100
재현성 설정 random_state=42 random_state=42

3. 평가 함수 작성하기

센서를 변경할 때마다 평가 코드를 다시 작성하지 않도록, 모델과 데이터를 입력받아 지표를 계산하는 함수를 사용합니다.

PYTHON · 실습 코드
def evaluate_model(model, X, y_true):
    """학습된 모델의 분류 지표를 계산합니다."""
    y_pred = model.predict(X)

    return {
        "Accuracy": accuracy_score(y_true, y_pred),
        "Macro F1": f1_score(
            y_true, y_pred,
            labels=[0, 1, 2, 3],
            average="macro", zero_division=0
        ),
        "Danger Recall": recall_score(
            y_true, y_pred,
            labels=[3],
            average="macro", zero_division=0
        )
    }
평가 지표 살펴볼 내용
Accuracy 전체 분류 정확도
Macro F1 네 상태를 같은 비중으로 반영한 F1-score
Danger Recall 실제 위험(3) 상태를 얼마나 찾아냈는지

4. 모델 및 결과를 누적하는 공통 실험 함수

이번 미션에서는 센서 수와 조합을 여러 번 바꿔 학습합니다. 매번 두 장비·두 알고리즘을 실행하고 결과를 모으기 위해 함수를 만듭니다.

같은 실험 이름으로 같은 센서 조합을 다시 실행할 경우 기존 결과를 갱신하며, 다른 센서 조합으로 바꾸려면 새로운 실험 이름을 사용합니다.

PYTHON · 실습 코드
ALGORITHMS = ["LogisticRegression", "RandomForest"]

# 실험의 학습 모델과 결과를 누적하는 공간
trained_models = {}
experiment_results = {}


def run_experiment(stage, features):
    """선택한 센서로 AGV/OHT의 두 모델을 학습·검증합니다."""
    features = list(features)

    # 선택한 센서가 유효한지 확인
    if not features or len(features) != len(set(features)):
        raise ValueError("특성 목록은 비어 있거나 중복되면 안 됩니다.")
    if not set(features).issubset(ALL_FEATURES):
        raise ValueError("ALL_FEATURES에 없는 센서가 포함되었습니다.")

    # 기존 실험 이름에 다른 센서를 덮어쓰지 않도록 확인
    for device in split_data:
        for algorithm in ALGORITHMS:
            key = (device, algorithm, stage)
            if key in experiment_results:
                if experiment_results[key]["Features"] != features:
                    raise ValueError(
                        f"'{stage}'에 다른 센서가 이미 기록되어 있습니다. "
                        "새로운 stage 이름을 사용하세요."
                    )

    for device, parts in split_data.items():
        X_train = parts["train"][features]
        y_train = parts["train"][TARGET_COL]
        X_val = parts["val"][features]
        y_val = parts["val"][TARGET_COL]

        for algorithm in ALGORITHMS:
            model = make_model(algorithm)

            # 학습 시간 측정 (환경에 따라 달라질 수 있음)
            start = time.perf_counter()
            model.fit(X_train, y_train)
            fit_seconds = time.perf_counter() - start

            scores = evaluate_model(model, X_val, y_val)
            key = (device, algorithm, stage)

            # (장비, 알고리즘, 실험명)으로 구분하여 보관
            trained_models[key] = model
            experiment_results[key] = {
                "Device": device,
                "Algorithm": algorithm,
                "Stage": stage,
                "Features": features.copy(),
                "Feature Count": len(features),
                "Fit Seconds": fit_seconds,
                **scores
            }

    return pd.DataFrame(list(experiment_results.values()))

trained_models에는 실제 학습한 모델이, experiment_results에는 센서 목록과 검증 결과가 저장됩니다. 여기서 Fit Seconds는 학습 시간의 참고값이며, 하드웨어·시스템 부하에 따라 달라질 수 있습니다.
