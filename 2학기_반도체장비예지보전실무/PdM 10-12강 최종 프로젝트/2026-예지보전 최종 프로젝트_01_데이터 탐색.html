ACTIVITY B. 상태에 따라 센서 값이 달라질까?

1. 센서 분포 확인하기

상태별 센서 값의 분포를 바이올린 플롯(Violin Plot)으로 살펴봅니다. 바이올린 플롯은 값이 어느 구간에 집중되는지, 얼마나 퍼져 있는지, 상태별로 얼마나 겹치는지 보여줍니다.

바이올린 플롯을 읽는 방법

  • 세로 위치: 센서 값의 크기를 나타냅니다.
  • 가로 폭: 해당 값 부근에 데이터가 얼마나 밀집되어 있는지 나타냅니다. 폭이 넓은 구간에 상대적으로 많은 값이 분포합니다.
  • 전체 길이와 형태: 값이 분포하는 범위와 밀집 구간을 살펴볼 수 있습니다.
  • 내부 선: 이번 코드에서는 중앙값과 사분위수를 표시합니다.

단, 바이올린 플롯은 데이터의 분포를 매끄럽게 추정하여 그립니다. 폭이 넓다고 해서 다른 바이올린보다 실제 표본 수가 반드시 많다는 뜻은 아닙니다. 표본 수가 적을 때는 매끄러운 형태가 실제 분포를 과장할 수도 있습니다.

먼저 내부 온도, 열화상 최대 온도, 전류 센서를 비교합니다.

Python · 실습 코드

    "NTC_temp",
    "IR_temp_max",
    "CT1_current"
]

# 목록에 있는 센서마다 바이올린 플롯 생성

    plt.figure(figsize=(8, 4))

        data=df,
        x="state",
        y=sensor,

    )
    plt.title(f"{TARGET}: {sensor} by State")
    plt.xlabel("State")
    plt.ylabel(sensor)
    plt.tight_layout()
    plt.show()
매개변수의미
x="state"장비 상태별로 분포 구분
y=sensor현재 선택한 센서 값 표시

cut=0추정 밀도의 범위를 실제 관측값 범위로 제한

ACTIVITY D

ACTIVITY D. 시간에 따른 센서 값과 장비 상태 관찰하기

1. 시간순 분석을 위한 준비

특정 시점에 측정된 값과 일정 시간 동안 변화한 모습은 서로 다른 정보를 제공합니다. 시간에 따른 변화를 올바르게 확인하려면 장비 구분, 측정 시각 정렬, 수집 간격 확인이 필요합니다.

2. 모든 측정 기록이 연속된 것은 아니다

이번 데이터에는 여러 장비의 측정 기록이 포함되어 있습니다. 같은 장비에서도 모든 기록이 연속적으로 수집된 것은 아닙니다. 다음 기록을 살펴보세요.

timestampNTC_temp
10:00:0127.1
10:00:0227.3
10:00:0327.5
14:30:0128.2
14:30:0228.4

앞의 세 기록은 1초 간격이지만, 세 번째와 네 번째 기록 사이에는 긴 공백이 있습니다. 이 데이터를 그대로 선으로 연결하면 실제로 측정되지 않은 시간의 변화까지 관찰된 것처럼 보일 수 있습니다. 서로 다른 장비의 기록을 이어 그리는 것도 잘못된 해석으로 이어집니다.

따라서 이번 실습에서는 같은 장비의 기록을 시간순으로 정렬하고, 직전 기록과의 시간 차이가 5분을 초과하면 새로운 수집 구간으로 나눕니다. 5분은 분석을 위한 실습 기준이며 실제 설비의 가동 시작·종료 시점과 일치한다고 볼 수는 없습니다.

3. 연속된 수집 구간 구분하기

Python · 실습 코드
# 기본은 전체 장비를 살펴봅니다. 특정 장비만 보려면 ID를 입력하세요.
DEVICE_ID = None  # 예: "agv01" 또는 "oht01" (현재 TARGET에 맞게)

# 선택한 장비만 추출하거나 전체 데이터를 사용
source_df = df if DEVICE_ID is None else df[df["device_id"] == DEVICE_ID]
if source_df.empty:
    raise ValueError(f"장비 ID를 확인하세요: {DEVICE_ID}")

# 장비별로 구분하고 시간순으로 정렬
plot_df = source_df.sort_values(
    ["device_id", "timestamp"]
).copy()

# 같은 장비에서 직전 기록과의 시간 차이를 초 단위로 계산
time_diff = (
    plot_df.groupby("device_id")["timestamp"]
    .diff()
    .dt.total_seconds()
)

# 각 장비의 첫 기록 또는 5분을 초과한 공백은 새 구간
new_segment = (
    time_diff.isna() |
    (time_diff > 300)
)

# True일 때마다 누적합이 증가하여 구간 번호 생성
plot_df["segment"] = new_segment.cumsum()

print("수집 구간 수:", plot_df["segment"].nunique())
코드역할
groupby("device_id")장비별로 기록을 구분
diff()같은 장비에서 직전 기록과의 차이 계산
dt.total_seconds()시간 차이를 초로 변환
time_diff.isna()각 장비의 첫 기록 확인
time_diff > 300직전 기록과 5분을 초과하여 떨어진 위치 확인
cumsum()새 구간이 나타날 때마다 번호 증가

groupby("device_id")를 사용하므로 장비가 바뀌는 지점에서 서로 다른 장비의 시간 차이를 계산하지 않습니다. 각 장비의 첫 기록은 이전 측정값이 없으므로 diff() 결과가 결측값입니다. new_segment가 True가 되는 지점마다 새 구간 번호가 부여됩니다.

4. 분석할 수집 구간 선택하기

이제 상태가 두 종류 이상 포함된 구간을 우선 선택하겠습니다. 해당 구간이 없다면 기록 수가 가장 많은 구간을 선택합니다.

Python · 실습 코드
# 구간별 데이터 수와 서로 다른 상태의 수
segment_info = plot_df.groupby("segment").agg(
    data_count=("state", "size"),
    state_count=("state", "nunique")
)

# 두 종류 이상의 상태를 포함한 구간을 후보로 선택
candidates = segment_info[
    segment_info["state_count"] >= 2
]

# 후보 중 데이터가 가장 많은 구간 선택
if candidates.empty:
    selected_segment = segment_info["data_count"].idxmax()
else:
    selected_segment = candidates["data_count"].idxmax()

# 선택된 구간만 시간순으로 추출
part = plot_df[
    plot_df["segment"] == selected_segment
].sort_values("timestamp")

print("선택 장비:", part["device_id"].iloc[0])
print("수집 구간:", selected_segment)
print("데이터 수:", len(part))
print("포함된 상태:", sorted(part["state"].unique()))
변수의미
segment_info구간별 데이터 수와 상태 종류 수
candidates서로 다른 상태가 2개 이상인 구간
selected_segment선택된 수집 구간 번호
part선택된 구간의 측정 기록

두 상태 이상이 포함되었다고 해서 상태가 정상에서 위험으로 순서대로 변한다고 단정할 수는 없습니다. 변화 방향은 그래프에서 확인하세요.

5. 센서 값과 장비 상태 시각화하기

선택한 구간의 센서 값과 장비 상태를 같은 시간축에 표시합니다.

Python · 실습 코드
# 변경해 볼 센서
SENSOR = "NTC_temp"

# 위쪽: 센서 값 / 아래쪽: 상태, 시간축 공유
fig, axes = plt.subplots(
    2, 1,
    figsize=(12, 7),
    sharex=True
)

axes[0].plot(
    part["timestamp"],
    part[SENSOR],
    color="steelblue"
)
axes[0].set_ylabel(SENSOR)
axes[0].set_title("Sensor Value")

# 상태는 계단 그래프로 표시
axes[1].step(
    part["timestamp"],
    part["state"],
    where="post",
    color="tomato"
)
axes[1].set_yticks([0, 1, 2, 3])
axes[1].set_ylabel("State")
axes[1].set_xlabel("Time")
axes[1].set_title("Equipment State")

for ax in axes:
    ax.grid(alpha=0.3)

plt.suptitle(f"{TARGET}: Sensor and State over Time")
plt.tight_layout()
plt.show()

sharex=True는 두 그래프에 동일한 시간축을 적용합니다. plot()은 센서 측정값을 선으로, step()은 상태값을 계단 형태로 표시합니다. 선은 기록된 점 사이를 연결한 것이며, 측정되지 않은 구간의 실제 변화까지 알려주지는 않습니다.
