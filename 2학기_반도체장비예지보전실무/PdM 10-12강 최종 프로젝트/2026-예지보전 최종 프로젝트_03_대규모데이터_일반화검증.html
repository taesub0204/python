01. 실무에서는 언제 이런 작업을 할까?

제조현장에 AI 모델을 적용하는 일은 학습 데이터에서 높은 정확도를 얻는 것으로 끝나지 않습니다. 개발한 모델이 다른 장비에서도 잘 작동하는지, 데이터를 추가 확보했을 때 재학습할 필요가 있는지 판단해야 합니다.

실무 상황 01

시범 장비에서는 잘 작동했는데, 다른 장비에서도 될까?

한 제조기업이 AGV 5대를 대상으로 장비 상태 분류 모델의 시범 프로젝트(PoC)를 진행했습니다. 실험 결과가 만족스럽자 담당 팀장이 묻습니다.

“5대에서는 잘 되는 걸 확인했어요. 다른 AGV에도 이 모델을 적용할 수 있나요?”

같은 종류의 장비라도 사용 기간, 부하, 운전 조건과 센서 상태는 다를 수 있습니다. 기존 모델을 다시 학습하지 않고 새로운 장비에서 먼저 평가하는 절차가 필요합니다.

검증할 문제 · 기존 모델의 일반화 성능
실무 상황 02

새로운 장비 데이터를 확보했으니 다시 학습해 볼까?

기존 모델의 적용 범위를 살펴보던 개발팀이 추가 장비의 데이터를 확보했습니다. 한 엔지니어가 제안합니다.

“처음에는 5대만 썼잖아요. 이제 16대의 데이터가 있으니 같은 센서와 알고리즘으로 다시 학습해 보죠.”

새 모델이 무조건 더 좋다고 가정할 수는 없습니다. 기존 모델과 신규 모델을 동일한 검증 데이터에서 비교해야 합니다.

세 가지 지표를 공통으로 사용합니다. Danger Recall은 실제 위험(3) 상태 중 모델이 위험으로 맞춘 비율입니다.

PYTHON · 실습 코드
def evaluate_model(model, X, y_true):
    y_pred = model.predict(X)
    return {
        "Accuracy": accuracy_score(y_true, y_pred),
        "Macro F1": f1_score(
            y_true, y_pred,
            labels=[0, 1, 2, 3],
            average="macro", zero_division=0
        ),
        "Danger Recall": recall_score(
            y_true, y_pred,
            labels=[3],
            average="macro", zero_division=0
        )
    }

scores_S = evaluate_model(model_S, X_val, y_val)

PYTHON · 실습 코드
def make_model(algorithm):
    if algorithm == "LogisticRegression":
        return Pipeline([
            ("scaler", StandardScaler()),
            ("classifier", LogisticRegression(
                max_iter=1500,
                class_weight="balanced",
                random_state=42
            ))
        ])
    if algorithm == "RandomForest":
        return RandomForestClassifier(
            n_estimators=100,
            class_weight="balanced",
            random_state=42,
            n_jobs=-1
        )
    raise ValueError(f"알 수 없는 알고리즘: {algorithm}")

model_L = make_model(ALGORITHM)

def evaluate_by_device(model, df, features):
    results = []

    for device_id in sorted(df["device_id"].unique()):
        part = df[df["device_id"] == device_id]
        X = part[features]
        y = part["state"]
        scores = evaluate_model(model, X, y)

        results.append({
            "device_id": device_id,
            "Macro F1": scores["Macro F1"],
            "Danger Recall": scores["Danger Recall"]
        })

    return pd.DataFrame(results)

반복할 때마다 검증용 장비 한 대의 데이터만 선택하고, 그 장비에서 모델 성능을 계산해 표에 누적합니다.
