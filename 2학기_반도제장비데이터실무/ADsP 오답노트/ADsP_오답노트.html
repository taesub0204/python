📊 PART 0. 노베이스 시험 직전 필수 도형 · 그래프 · 핵심 도식

① DIKW 피라미드 (4번) & DW vs DM / OLTP vs OLAP (8번)
[7번 NoSQL] Redis=인메모리 키-값 | MongoDB=문서(Document) | HBase=컬럼(Column)
[8번 DW/DM] DW=전사 통합(대규모) vs DM=부서별(소규모) | OLTP=실시간 거래 vs OLAP=다차원 분석
② 분석 기획 4유형 매트릭스 (21번) & 과제 발굴 (29번)
구분 (21번) 분석 방법(How) 앎(O) 분석 방법(How) 모름(X)
분석 대상(What) 앎(O) 최적화 (Optimization) 솔루션 (Solution)
분석 대상(What) 모름(X) ★ 통찰 (Insight) [정답] 발견 (Discovery)
• 하향식(Top-Down): 문제 주어짐 → 수렴(Converge) · Why 관점 · 5영역 단순화 캔버스(31번)
• 상향식(Bottom-Up, 29번): 데이터 기반 → 발산(Diverge) · What 관점 · 프로토타이핑 · 비지도학습(군집·연관)
③ ROI 우선순위 사분면 (34·35번) & 분석 조직 3유형 (39번)
[34·35번] 난이도=3V(비용), 시급성=Value(효과) | 시급성 기준: 현재·쉬움 → 현재·어려움 → 미래·어려움
[39번 조직] 집중형(전담부서) vs 기능형(별도 조직 없이 현업 직접·과거실적 국한) vs 분산형(현업 파견)
④ R matrix 열 우선 & apply (44번) · 층화 vs 집락추출 (51번)
⑤ 확률·표준오차·신뢰구간 (53~56번) & 제1·2종 오류 (57·58번)
[57번 p-value] 귀무가설(H₀)이 참일 때 극단값 나올 확률 (p < α 이면 H₀ 기각)
[58번 오류] 표본 크기 고정 시 제1종 오류(α)를 줄이면 제2종 오류(β)는 커짐 (상충·반비례 관계)
⑥ 시계열 AR vs MA 절단 도식 (69번) & 주성분 누적기여율 (71번)
⑦ 데이터 분할·과적합 곡선 (76·80번) & 오즈비·부트스트랩 (77~79번)
[78번 로지스틱] 계수 추정은 최소제곱법이 아닌 최대우도추정법(MLE) 사용
[79번 오즈비] x가 1 증가 시 '오즈(승산)'가 exp(β)=2배 증가 ('발생 확률이 2배'는 오답!)
⑧ 의사결정나무 지니지수·알고리즘 (82·83번) & 배깅 vs 부스팅 (84번)
⑨ 인공신경망(3-4-1) 파라미터 21개 (87번) & 혼동행렬 민감도 (89번)
⑩ 유클리드 vs 맨하탄 거리 (93번) & 연관규칙 3대 지표 (97·98번)
[92번 실루엣] -1~1 범위(1에 가까울수록 우수) | [95번 k-medoids] 실제 관측치 중심(이상값 보완)
[96번 SOM] 2층 경쟁학습(역전파X·빠름) | [100번 FP-Growth] DB 2회만 스캔(Apriori는 반복 스캔)

1과목 데이터 이해 — 오답 노트 (총 10문항)

번호 출제 주제 정답 노베이스 1초 컷 핵심 해설 & 시험장 암기 공식
4번
오답		 DIKW 피라미드 ③ 지식 "A마트 연필이 더 싸므로 A마트에서 사야겠다(의사결정·행동)" = 지식(Knowledge) 단계
암기공식• 데이터(100원/200원) → 정보(A가 더 싸다) → 지식(A에서 사야겠다) → 지혜(A의 다른 상품도 쌀 것이다)
6번
오답		 SQL 명령어 분류 ④ TRUNCATE는 테이블 구조는 남기고 데이터를 전부 비우는 DDL(데이터 정의어)입니다 (DML 아님!)
암기공식• DDL(정의): CREATE, ALTER, DROP, RENAME, TRUNCATE / • DML(조작): SELECT, INSERT, UPDATE, DELETE / • DCL(제어): GRANT, REVOKE
7번
오답		 NoSQL 저장 구조 ① Redis = 인메모리 키-값(Key-Value) 저장소 (정답 ①)
암기공식• 키-값: Redis, DynamoDB / • 문서(Document): MongoDB / • 컬럼(Column): HBase, Cassandra / • 그래프: Neo4j
8번
오답		 DW / DM / OLAP ④ (ㄱ,ㄷ,ㅁ) DW 4대 특징 = 주제지향·통합·시계열·비휘발성(조회 위주) / ETL = 추출(Extract)→변환(Transform)→적재(Load)
암기공식• DW(전사 대규모) vs DM(부서 소규모) [ㄴ반대] / • OLTP(실시간 거래) vs OLAP(다차원 분석) [ㄹ반대]
9번
오답		 빅데이터의 정의 ① 맥킨지(McKinsey)는 기존 DB 관리·분석 역량을 넘어서는 데이터 '규모(Volume)' 관점에서 정의했습니다
암기공식• IDC = 차세대 기술·아키텍처 관점 / • 정의 범위는 [규모 → 기술 → 인재·조직] 순으로 점점 넓어짐
12번
오답		 빅데이터 4대 변화 ① 빅데이터의 본질적 변화는 '양보다 질'이 아니라 '질보다 양'(데이터가 많으면 일부 오류는 상쇄됨)입니다!
암기공식[4대 변화 암기] ① 사전→사후처리, ② 표본→전수조사, ③ 질보다 양, ④ 인과→상관관계
13번
오답		 빅데이터 활용 테크닉 ④ "새로운 환불 정책에 대한 고객의 평가·반응은?" → 유형분석이 아니라 감정분석(Sentiment Analysis)입니다
암기공식• 유형분석: "이 고객은 어떤 특성 그룹에 속하는가?" / • 유전 알고리즘: "최대 시청률 프로그램 시간대 편성(최적화)"
14번
오답		 위기 요인과 통제 방안 ④ 데이터 오용의 통제 방안 = 알고리즘 접근권 허용 및 알고리즈미스트(Algorithmist) 양성
암기공식• 사생활 침해 → 동의제에서 책임제로 / • 책임 원칙 훼손 → 예측이 아닌 결과 기반 책임 원칙 고수
15번
오답		 마이데이터·개인정보 ③ 마이데이터(MyData)는 정보 주체(개인)의 전송요구권(적극적 의사)에 기반한 제도입니다 ('동의 없이 제공' X)
암기공식• 옵트인 = 사전 동의 후 수집 / • 옵트아웃 = 일단 수집 후 사후 거부 허용 / • 가명정보 = 통계·연구 목적 동의 없이 활용 가능
19번
오답		 빅데이터 회의론 원인 ② (ㄱ,ㄴ) 빅데이터 회의론 2대 원인 = ① 과거 CRM 공포(투자 실패 부정적 학습효과), ② 성공 사례의 과대 포장
암기공식알고리즘 부재나 저장 비용 상승 때문에 회의론이 생긴 것이 아님(저장 비용은 오히려 하락함)

2과목 데이터 분석 기획 — 오답 노트 (총 12문항)

번호 출제 주제 정답 노베이스 1초 컷 핵심 해설 & 시험장 암기 공식
21번
오답		 분석 주제 4유형 ③ 통찰 분석 대상(What)은 모르지만(X) 분석 방법(How)은 알고 있는(O) 경우 = 통찰(Insight)
암기공식• 대상O·방법O = 최적화 / • 대상O·방법X = 솔루션 / • 대상X·방법O = 통찰 / • 대상X·방법X = 발견
23번
오답		 분석 기획 고려사항 ② (ㄱ,ㄴ,ㄷ,ㄹ) 분석 기획 3대 고려사항 = ① 가용 데이터 파악, ② 적절한 유스케이스 탐색, ③ 장애 요소 사전 계획(고정관념·편향·프레이밍 효과)
암기공식• 텍스트·이미지·영상은 '정형'이 아니라 '비정형 데이터'이므로 RDB에 그대로 적재 불가 (ㅁ 오답)
24번
미응답		 개발 모델 (미응답) ① 나선형(Spiral) 모델은 반복 개발과 위험 분석을 수행하므로 관리가 복잡하며 대규모·고위험 프로젝트에 적합합니다
암기공식• 폭포수 모델 = 순차 진행 / • 프로토타입 모델 = 요구사항이 불명확할 때 시제품으로 점진적 개선
25번
오답		 KDD 분석 방법론 ③ 변환 변수 선택·생성, 차원 축소(PCA 등), 학습용/시험용 데이터 분리를 수행하는 단계 = 데이터 변환(Transformation)
암기공식• KDD 5단계: 데이터셋 선택 → 전처리(결측값·이상값·잡음 처리) → 변환(변수생성·차원축소·분할) → 마이닝 → 해석/평가
28번
오답		 빅데이터 분석 방법론 ③ 모델 발전 계획 수립은 시스템 구현 단계가 아니라 마지막 5단계인 [평가 및 전개] 단계의 태스크입니다
암기공식• 빅데이터 방법론 5단계: 분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가 및 전개(모델 발전 계획)
29번
오답		 하향식 vs 상향식 ④ 상향식(Bottom-Up) 접근법에서는 군집분석·연관분석 등 비지도학습 기법이 주로 활용됩니다
암기공식• 하향식 = 수렴(Converge)·Why 관점·체계적 / • 상향식 = 발산(Diverge)·What 관점·프로토타이핑(시행착오)·비지도학습
31번
오답		 하향식 문제 탐색 ① 비즈니스 모델 캔버스 9개 블록을 그대로 쓰지 않고 5개 영역(업무·제품·고객 + 규제와 감사·지원 인프라)으로 단순화합니다
암기공식• 하향식 4단계: 문제 탐색(5영역 캔버스) → 문제 정의(분석 문제로 변환) → 해결방안 탐색 → 타당성 검토(경제·기술)
33번
오답		 마스터플랜 고려요소 ③ 전략적 중요도는 '우선순위' 고려 요소입니다! 적용 범위·방식 고려 요소는 '~적용 수준' 3가지입니다
암기공식• 우선순위 3요소: 전략적 중요도, 비즈니스 성과(ROI), 실행 용이성 / • 적용 범위·방식 3요소: 업무 내재화·분석 데이터·기술 적용 수준
34번
오답		 ROI 관점 평가 기준 ② 투자 비용 요소인 3V(Volume·Variety·Velocity)는 '난이도'를, 비즈니스 효과인 Value(가치)는 '시급성'을 판단합니다
암기공식• 투자 비용(난이도) = 3V(데이터 획득·저장·가공 비용) / • 비즈니스 효과(시급성) = Value(전략적 중요도·성과)
35번
오답		 우선순위 사분면 순서 ④ 시급성 기준(현재 과제 우선) 추진 순서 = 현재·쉬움(1순위) → 현재·어려움(2순위) → 미래·어려움
암기공식• 난이도 기준(쉬운 과제 우선)일 때가 [현재·쉬움 → 미래·쉬움 → 미래·어려움](②번 보기)입니다. 시험 빈출 함정!
36번
오답		 분석 거버넌스 5요소 ① (ㄱ~ㅁ) 분석 거버넌스 체계 5대 구성요소 = 조직(O), 프로세스(P), 시스템(S), 데이터(D), 인력·교육(H) ('예산'은 제외!)
암기공식• 암기팁: 조·프·시·데·인 (연간 분석 예산(ㅂ)은 거버넌스 체계 5대 구성요소에 포함되지 않음)
39번
오답		 분석 조직 구조 3유형 ② 기능형 별도 분석 조직 없이 각 현업 부서에서 직접 분석하여 과거 실적 분석에 국한되기 쉬운 구조 = 기능형 구조
암기공식• 집중형 = 전사 전담 분석조직 별도 설치(현업과 이원화 가능성) / • 분산형 = 분석 전문인력을 현업 부서로 파견 배치

3과목 데이터 분석 — 오답 노트 (총 37문항)

번호 출제 주제 정답 노베이스 1초 컷 핵심 해설 & 시험장 암기 공식
42번
오답		 R 산술 연산자 ④ (1, 2) 7 %% 3 = 1 (나머지 연산) / 7 %/% 3 = 2 (정수 몫 연산)
암기공식• %% = 나눗셈의 나머지 / • %/% = 나눗셈의 정수 몫 (가운데 슬래시 / 가 있으면 몫!)
43번
오답		 R rep() 반복 함수 ③ (1 1 2 2) rep(c(1, 2), each = 2)는 각 원소를 2번씩 먼저 반복하므로 1 1 2 2가 출력됩니다
암기공식• each = 2 → 원소별 각각 반복(1 1 2 2) / • times = 2 → 벡터 통째로 반복(1 2 1 2)
44번
오답		 R matrix & apply ① (3 7 11) matrix(1:6, nrow=2)는 열 우선 채움([1,3,5 / 2,4,6]) → apply(m, 2, sum)은 열(2) 합계이므로 3, 7, 11
암기공식• apply 두 번째 인자: 1 = 행(Row) 단위 합계(9, 12) / 2 = 열(Column) 단위 합계(3, 7, 11)
45번
