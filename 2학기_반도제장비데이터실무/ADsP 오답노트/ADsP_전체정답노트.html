[39번 조직] 집중형(전담부서) vs 기능형(별도 조직 없이 현업 직접·과거실적 국한) vs 분산형(현업 파견)

⑦ 데이터 분할·과적합 곡선 (76·80번) & 오즈비·부트스트랩 (77~79번)
[78번 로지스틱] 계수 추정은 최소제곱법이 아닌 최대우도추정법(MLE) 사용

⑩ 유클리드 vs 맨하탄 거리 (93번) & 연관규칙 3대 지표 (97·98번)

✅ PART 1. 1~100번 전 문항 핵심 정답노트 (찍어서 맞은 문제 완벽 복습)

1과목 데이터 이해 (1번 ~ 20번) (전체 20문항 — 맞힌 문항 10개 · 오답 10개 모두 수록)

번호 내 상태 출제 주제 정답 노베이스 전 문항 핵심 요약 & 찍어서 맞힌 문제 완벽 복습 포인트
1번 정답(점검) 데이터의 특성 ① 존재적 특성 = 있는 그대로의 객관적 사실(Fact) (예: 매장 온도 21℃) / 당위적 특성 = 추론·예측·전망·추정의 근거
핵심요약데이터는 독자적으로 존재하기보다 다른 객체와의 상호관계 속에서 가치를 가짐
2번 정답(점검) 정형·반정형·비정형 ④ 반정형 데이터 = 데이터 내부에 스키마(메타데이터)를 포함 (웹 로그, 센서 데이터, XML, JSON, HTML)
핵심요약정형 = RDB 테이블, 스프레드시트 / 비정형 = 소셜 자유 텍스트, 영상, 음성, 이미지
3번 정답(점검) SECI 지식변환 ② 표출화 개인 머릿속의 암묵지를 매뉴얼·문서 등 형식지로 변환하는 단계 = 표출화(Externalization)
핵심요약공통화(암→암) → 표출화(암→형) → 연결화(형→형) → 내면화(형→암) 4단계 순환
4번 오답 복습 DIKW 피라미드 ③ 지식 "A마트 연필이 더 싸므로 A마트에서 사야겠다(의사결정·행동)" = 지식(Knowledge) 단계
핵심요약• 데이터(100원/200원) → 정보(A가 더 싸다) → 지식(A에서 사야겠다) → 지혜(A의 다른 상품도 쌀 것이다)
5번 정답(점검) DB 특징과 설계 ① 통합된 데이터(Integrated Data)는 데이터 중복을 최소화한 상태입니다 ('여러 곳에 중복 저장'이 오답!)
핵심요약DB 설계 순서: 요구사항 분석 → 개념적(ERD) → 논리적(정규화) → 물리적(인덱스·성능) 설계
6번 오답 복습 SQL 명령어 분류 ④ TRUNCATE는 테이블 구조는 남기고 데이터를 전부 비우는 DDL(데이터 정의어)입니다 (DML 아님!)
핵심요약• DDL(정의): CREATE, ALTER, DROP, RENAME, TRUNCATE / • DML(조작): SELECT, INSERT, UPDATE, DELETE / • DCL(제어): GRANT, REVOKE
7번 오답 복습 NoSQL 저장 구조 ① Redis = 인메모리 키-값(Key-Value) 저장소 (정답 ①)
핵심요약• 키-값: Redis, DynamoDB / • 문서(Document): MongoDB / • 컬럼(Column): HBase, Cassandra / • 그래프: Neo4j
8번 오답 복습 DW / DM / OLAP ④ (ㄱ,ㄷ,ㅁ) DW 4대 특징 = 주제지향·통합·시계열·비휘발성(조회 위주) / ETL = 추출(Extract)→변환(Transform)→적재(Load)
핵심요약• DW(전사 대규모) vs DM(부서 소규모) [ㄴ반대] / • OLTP(실시간 거래) vs OLAP(다차원 분석) [ㄹ반대]
9번 오답 복습 빅데이터의 정의 ① 맥킨지(McKinsey)는 기존 DB 관리·분석 역량을 넘어서는 데이터 '규모(Volume)' 관점에서 정의했습니다
핵심요약• IDC = 차세대 기술·아키텍처 관점 / • 정의 범위는 [규모 → 기술 → 인재·조직] 순으로 점점 넓어짐
10번 정답(점검) 빅데이터 3V·가치 ④ (ㄱ,ㄷ,ㅁ) 더그 래니의 기본 3V = Volume(규모), Variety(다양성), Velocity(속도) / 출현 배경 = 산업계·학계·기술 발전
핵심요약• Veracity(정확성)·Value(가치)는 4V·5V 확장 요소 / • 가치 산정 난해 이유 = 활용 방식 변화, 새로운 가치 창출, 분석 기술 발전
11번 정답(점검) 빅데이터 비유 ② 렌즈(Lens) = 현미경이 생물학 발전에 기여했듯 산업 발전에 기여 (대표 예시: 구글 Ngram Viewer)
핵심요약• 플랫폼 = 공동 활용 구조물(카카오톡·페이스북) / • 21세기 원유 = 신산업 창출 / • 석탄·철 = 사회·경제 혁명적 변화
12번 오답 복습 빅데이터 4대 변화 ① 빅데이터의 본질적 변화는 '양보다 질'이 아니라 '질보다 양'(데이터가 많으면 일부 오류는 상쇄됨)입니다!
핵심요약[4대 변화 암기] ① 사전→사후처리, ② 표본→전수조사, ③ 질보다 양, ④ 인과→상관관계
13번 오답 복습 빅데이터 활용 테크닉 ④ "새로운 환불 정책에 대한 고객의 평가·반응은?" → 유형분석이 아니라 감정분석(Sentiment Analysis)입니다
핵심요약• 유형분석: "이 고객은 어떤 특성 그룹에 속하는가?" / • 유전 알고리즘: "최대 시청률 프로그램 시간대 편성(최적화)"
14번 오답 복습 위기 요인과 통제 방안 ④ 데이터 오용의 통제 방안 = 알고리즘 접근권 허용 및 알고리즈미스트(Algorithmist) 양성
핵심요약• 사생활 침해 → 동의제에서 책임제로 / • 책임 원칙 훼손 → 예측이 아닌 결과 기반 책임 원칙 고수
15번 오답 복습 마이데이터·개인정보 ③ 마이데이터(MyData)는 정보 주체(개인)의 전송요구권(적극적 의사)에 기반한 제도입니다 ('동의 없이 제공' X)
핵심요약• 옵트인 = 사전 동의 후 수집 / • 옵트아웃 = 일단 수집 후 사후 거부 허용 / • 가명정보 = 통계·연구 목적 동의 없이 활용 가능
16번 정답(점검) 사이언티스트 역량 ② (ㄴ,ㄷ,ㅁ) 소프트 스킬 3가지 = 통찰력 있는 분석(창의적 사고), 설득력 있는 전달(스토리텔링), 다분야 간 협력(소통)
핵심요약• 하드 스킬 = 빅데이터 이론적 지식, 분석 기술에 대한 숙련
17번 정답(점검) 가치 패러다임 변화 ① 가치 패러다임 순서 = 디지털화(Digitalization) → 연결(Connection) → 에이전시(Agency)
핵심요약• 디지털화(아날로그→디지털, OS) → 연결(인터넷·검색엔진) → 에이전시(IoT·복잡한 연결을 대신 관리)
18번 정답(점검) 개인정보 비식별화 ④ 식별 가능한 속성 자체를 지우는 것은 '데이터 삭제'입니다. 총계처리는 합계·평균 등 통계값으로 대체하는 기법!
핵심요약• 가명처리(홍길동→임꺽정) / • 데이터 마스킹(홍길동→홍○○) / • 데이터 범주화(35세→30~40세)
19번 오답 복습 빅데이터 회의론 원인 ② (ㄱ,ㄴ) 빅데이터 회의론 2대 원인 = ① 과거 CRM 공포(투자 실패 부정적 학습효과), ② 성공 사례의 과대 포장
핵심요약알고리즘 부재나 저장 비용 상승 때문에 회의론이 생긴 것이 아님(저장 비용은 오히려 하락함)
20번 정답(점검) 하둡 · 스파크 · 클라우드 ① HDFS는 블록 분할·복제 저장, 맵리듀스(MapReduce)는 Map(키-값 생성) → Reduce(집계) 병렬 처리
핵심요약• 스파크(Spark) = 인메모리 방식(반복 분석 빠름) vs 맵리듀스 = 디스크 기반 / • NoSQL = 유연한 스키마·수평 확장

2과목 데이터 분석 기획 (21번 ~ 40번) (전체 20문항 — 맞힌 문항 8개 · 오답 12개 모두 수록)

번호 내 상태 출제 주제 정답 노베이스 전 문항 핵심 요약 & 찍어서 맞힌 문제 완벽 복습 포인트
21번 오답 복습 분석 주제 4유형 ③ 통찰 분석 대상(What)은 모르지만(X) 분석 방법(How)은 알고 있는(O) 경우 = 통찰(Insight)
핵심요약• 대상O·방법O = 최적화 / • 대상O·방법X = 솔루션 / • 대상X·방법O = 통찰 / • 대상X·방법X = 발견
22번 정답(점검) 목표 시점별 기획 ③ 과제 중심적 접근(단기) = Speed & Test, Quick-Win, Problem Solving (당면 과제 빠르게 해결)
핵심요약• 장기적 마스터플랜 = Accuracy & Deploy, Long Term View, Problem Definition (두 방식을 융합해 활용)
23번 오답 복습 분석 기획 고려사항 ② (ㄱ,ㄴ,ㄷ,ㄹ) 분석 기획 3대 고려사항 = ① 가용 데이터 파악, ② 적절한 유스케이스 탐색, ③ 장애 요소 사전 계획(고정관념·편향·프레이밍 효과)
핵심요약• 텍스트·이미지·영상은 '정형'이 아니라 '비정형 데이터'이므로 RDB에 그대로 적재 불가 (ㅁ 오답)

56번 오답 복습 모평균 95% 신뢰구간 ④ 100 ± 3.92 95% 신뢰구간 = x̄ ± 1.96 × (σ / √n) = 100 ± 1.96 × (20 / √100) = 100 ± 1.96 × 2 = 100 ± 3.92
