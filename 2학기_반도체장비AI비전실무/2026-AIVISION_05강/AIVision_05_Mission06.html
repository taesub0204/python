Mission 06. 회전 각도별 CNN 학습하고 저장하기

이미지 데이터 증강과 재현 가능한 실험

학습 목표
  • 회전 범위만 변경하는 비교 실험을 반복문으로 구성할 수 있다.
  • 시드·데이터 분할·모델 구조 등 실험 조건을 동일하게 유지할 수 있다.
  • 학습한 모델과 에포크별 학습 기록을 파일로 저장하고, 학습과 평가를 구분할 수 있다.

1. 이번 실험에서는 무엇을 바꿀까?

Mission 05에서 create_cnn_model()과 create_experiment_datasets()를 만들었다. 이제 이 함수를 사용해 회전 각도만 바꾸면서 CNN을 각각 처음부터 학습해보자.

실험회전 범위함수 전달값저장 파일명
A회전 없음0cnn_rotation_0.keras
B±15°15cnn_rotation_15.keras
C±45°45cnn_rotation_45.keras
D±90°90cnn_rotation_90.keras

네 실험에서 CNN 구조, 데이터 분할, 에포크, 배치 크기, 시드는 가능한 한 동일하게 유지한다. 이 실험의 유일한 의도적 변경 변수는 회전 범위다.

회전 각도 리스트 [0, 15, 45, 90]하나씩 반복
↓
데이터셋 준비 → 새 CNN 생성 → 학습동일한 시드와 학습 설정
↓
모델 파일 + 학습 기록 저장다음 회전 각도로 진행
회전이 없는 모델도 RandomRotation(factor=0)를 포함하지만 실제 이미지 회전은 발생하지 않는다. 실험의 기준 모델로 사용할 수 있다.

2. 실험 파일을 저장할 위치 정하기

Colab의 임시 저장 공간은 런타임이 초기화되면 사라질 수 있다. 따라서 학습이 끝난 모델은 Google Drive에 저장하자. 이미 Drive를 연결했다면 아래 코드에서 경로만 자신의 폴더에 맞게 수정한다.

PYTHON · 저장 폴더 준비
import os

# 사전 준비에서 설정한 root_path 아래에 모델 저장 폴더를 만든다.
# 문자열 + 파일명으로 경로를 연결하므로 끝의 /를 유지한다.
MODEL_DIR = root_path + "models/"
os.makedirs(MODEL_DIR, exist_ok=True)

print("저장 폴더:", MODEL_DIR)

os.makedirs(MODEL_DIR, exist_ok=True)는 저장 폴더가 없으면 만들고, 이미 있으면 그대로 사용한다. MODEL_DIR은 문자열이므로 끝에 /를 포함한다.

확인: Colab에서 Drive를 아직 마운트하지 않았다면 먼저 from google.colab import drive와 drive.mount('/content/drive')를 실행해야 한다. 로컬 PC라면 MODEL_DIR을 자신의 저장 경로로 바꾸면 된다.

3. 반복 실험 코드 구성하기

회전 각도가 네 개이므로 같은 코드를 네 번 복사하는 대신 for 반복문을 사용한다. Mission 05에서 작성한 두 함수와 SEED, EPOCHS 등의 상수를 그대로 활용하자.

코드 작성 미션
  1. 회전 각도 네 개를 리스트에 저장한다.
  2. 반복문에서 매 실험 시작 시 시드를 재설정한다.
  3. 실험용 데이터셋과 새 CNN 모델을 생성한다.
  4. fit()으로 학습한 뒤 모델을 해당 각도 이름으로 저장한다.

    keras.utils.set_random_seed(SEED)

여기서 create_cnn_model()은 호출할 때마다 시드를 다시 설정하도록 만든 함수이므로 모델 초기화 조건을 최대한 동일하게 맞출 수 있다. 반복문 맨 앞의 시드 설정은 데이터셋을 만드는 과정까지 함께 같은 출발점으로 맞추기 위한 것이다.

학습은 각 모델마다 EPOCHS만큼 진행된다. 네 모델을 각각 학습하므로 전체 실행 시간은 길어질 수 있다.

실행 전 확인: Mission 05에서 create_cnn_model()의 CNN 레이어를 완성했는지, class_names와 TRAIN_DIR 등이 준비되어 있는지 확인하자.

4. 학습 기록(History)도 함께 저장하기

fit()의 반환값인 history_exp에는 에포크별 학습 정확도와 손실, 검증 정확도와 손실이 기록된다. 그러나 반복문을 한 번 더 돌면 이 변수에는 마지막 실험의 History만 남는다.

또한 .keras 파일을 저장하더라도 fit()이 반환한 과거 에포크별 기록 전체가 자동으로 남지는 않는다. 실험 결과를 나중에 비교할 수 있도록 CSV로 따로 저장하자.

PYTHON · 반복문 안에 추가할 History 저장 코드
# model_exp.save(filename) 아래에 이어서 작성
    # 에포크별 학습/검증 지표를 표로 변환
    history_df = pd.DataFrame(history_exp.history)
    history_file = MODEL_DIR + f"cnn_rotation_{degree}_history.csv"
    history_df.to_csv(history_file, index=False)
    print("학습 기록 저장:", history_file)

이 코드는 3번 반복문 안에서 모델을 저장한 직후에 추가한다. 새 셀에 들여쓰기된 코드만 따로 실행하는 것이 아니다.

파일저장하는 것
cnn_rotation_45.keras학습한 모델과 가중치
cnn_rotation_45_history.csv에포크별 accuracy, loss, val_accuracy, val_loss

History 파일은 별도의 재학습 없이 학습 곡선을 그리는 데 사용할 수 있다.

5. 학습과 결과 분석을 분리하는 이유

모델을 학습하는 코드와 결과를 비교하는 코드를 분리하면 편리하다. 예를 들어 Colab 연결이 중간에 끊기더라도 이미 저장된 모델을 다시 학습할 필요 없이 불러와 평가할 수 있다.

학습 단계
새 모델 생성
fit()으로 학습
save()로 파일 저장

시간이 많이 걸리므로 완료한 모델부터 보관한다.

분석 단계
저장 파일 불러오기
evaluate()로 평가
결과표 · 혼동행렬 작성

필요할 때 반복 실행해 결과를 확인할 수 있다.

이번 미션의 중심 작업은 학습하고 파일로 저장하는 것이다. 성능지표를 한 번에 비교하는 코드는 다음 분석 단계에서 작성한다.

PYTHON · 파일이 제대로 저장되었는지 확인
# 문자열 경로의 존재 여부는 os.path.exists()로 확인한다.
import os

for degree in rotation_degrees:
    filename = MODEL_DIR + f"cnn_rotation_{degree}.keras"
    print(degree, "° :", "저장 완료" if os.path.exists(filename) else "파일 없음")

위 코드는 네 실험이 전부 끝난 뒤 실행한다. 학습이 중간에 멈췄다면 저장이 끝나지 않은 각도만 선택해 다시 실행할 수 있다.

PYTHON · 실패한 각도만 다시 학습하기 위한 리스트 예시
# 예: 90° 모델만 저장하지 못했을 때

# 위의 학습 반복문을 다시 실행한다.
파일이 존재하는지만 확인한 것이므로 모델의 정상 로드 여부까지 보장하지는 않는다. 중요한 모델은 이후 keras.models.load_model()로 불러와 확인할 수 있다. 파일명이 같으면 저장 시 기존 파일이 갱신되므로, 재학습 시에는 필요한 파일을 덮어쓰는지 확인하자.
