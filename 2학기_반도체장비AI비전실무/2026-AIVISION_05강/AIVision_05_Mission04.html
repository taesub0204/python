Mission 04. 증강 CNN 학습하고 성능 비교하기

이미지 데이터 증강과 재현 가능한 실험

학습 목표
  • 기존 CNN과 같은 조건으로 회전 증강 CNN을 학습할 수 있다.
  • 저장된 기존 모델과 증강 모델을 동일한 테스트 데이터로 평가할 수 있다.
  • 정확도 차이를 관찰하고, 데이터 증강의 효과를 성급하게 단정하지 않는다.

1. 이번 실험에서 확인할 질문

Mission 03에서 4강 CNN 앞에 회전 증강 레이어를 추가해 model_aug를 만들었다. 이번에는 새 모델을 학습하여 회전 증강이 웨이퍼맵 분류 성능에 어떤 영향을 주는지 확인한다.

4강 CNN 회전 증강 없음 · 기존 학습 모델
↕ 비교
5강 CNN 회전 범위 ±90° · 새로 학습할 모델
↓
동일한 test_ds로 평가 테스트 정확도 · 손실 비교

실험 가설의 예: “회전 증강을 적용하면 원본에 없는 방향의 결함 패턴까지 학습하여 정확도가 높아질 것이다.” 반대로 성능이 낮아질 가능성도 있다. 어떤 결과가 나와도 관찰하고 해석하는 것이 실험의 목적이다.

2. 학습 조건 확인하기

한 실험에서 바꾸려는 조건은 회전 증강 적용 여부이다. 기존 모델과 비교할 때 CNN 구조와 학습 설정을 같게 유지해야 차이를 해석하기 쉽다.

항목4강 기존 CNN5강 증강 CNN
입력 이미지64 × 64 × 3동일
학습 데이터train_ds동일
검증 데이터val_ds동일
테스트 데이터test_ds동일
배치 크기 / 에포크32 / 10동일
CNN 구조 / 학습 설정4강 설정동일
회전 증강없음±90°
시작 전 확인
  1. model_aug.summary()에서 증강 레이어와 기존 CNN 구조를 확인한다.
  2. train_ds, val_ds, test_ds가 생성되어 있는지 확인한다.
  3. 4강 모델 파일의 저장 위치를 확인한다. 비교할 때 다시 불러올 예정이다.

이번 미션에서는 먼저 한 번 학습하고 결과를 관찰한다. 가중치 초기화, 셔플 등의 무작위성을 통제하는 시드 고정 실험은 이후 미션에서 다룬다. 따라서 여기서 생긴 정확도 차이를 오직 회전 증강 때문이라고 확정할 수는 없다.

3. 증강 CNN 학습하기

4강 모델에서 사용한 손실 함수, 옵티마이저, 평가 지표를 확인하고 새 모델에도 동일하게 설정한다. 다음 코드를 작성해보자.

PYTHON · 학습 설정
# 기존 CNN과 동일한 학습 설정
model_aug.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

compile()은 학습 방법을 설정하고, fit()은 실제 학습을 진행한다. 학습에 사용하는 것은 원본 train_ds지만, 모델 내부의 RandomRotation이 훈련 단계에서 이미지를 무작위로 회전시킨다.

PYTHON · 증강 CNN 학습
# 학습 과정의 에포크별 결과를 history_aug에 기록
history_aug = model_aug.fit(
    train_ds,
    validation_data=val_ds,
    epochs=EPOCHS
)

history_aug에는 에포크마다 계산된 학습·검증 정확도와 손실이 기록된다. 학습이 끝나면 다음 코드로 확인해보자.

PYTHON · 학습 기록 확인
print(history_aug.history.keys())

model_aug는 새로 생성한 모델이어야 한다. 4강의 학습된 모델을 계속 학습시키면 “회전 증강을 추가한 새 모델”과의 비교가 아니라 추가 학습 효과까지 포함된 실험이 된다.

4. 기존 모델과 증강 모델 평가하기

4강 모델이 현재 메모리에 없다면 저장한 .keras 파일을 불러오자. 아래 경로를 실제 저장 경로에 맞게 수정한다.

PYTHON · 기존 CNN 불러오기
# 실제 4강 모델의 저장 경로로 수정
model = keras.models.load_model("기존모델파일.keras")

두 모델 모두 동일한 test_ds로 평가한다. evaluate()에서는 증강 레이어가 추론 모드로 실행되므로 테스트 이미지는 회전하지 않는다.

PYTHON · 테스트 성능 비교
# 기존 CNN
loss, acc = model.evaluate(test_ds, verbose=0)

# 회전 증강 CNN
loss_aug, acc_aug = model_aug.evaluate(test_ds, verbose=0)

print(f"기존 CNN 정확도: {acc:.4f}")
print(f"증강 CNN 정확도: {acc_aug:.4f}")
실험 결과 기록
  1. 기존 CNN의 정확도를 기록한다.
  2. 증강 CNN의 정확도를 기록한다.
  3. 두 결과 중 어느 쪽이 높았는지 확인한다. 결과를 예상과 비교한다.

5. 학습 모델 저장하기

학습에 시간이 걸린 모델은 파일로 저장해두면 필요할 때 다시 불러와 평가할 수 있다. 회전 조건을 알아볼 수 있는 파일명을 사용하자.

PYTHON · 모델 저장
# Google Drive의 실제 저장 경로로 변경
model_aug.save("cnn_rotation_90.keras")

Colab에서 작업한다면 Google Drive에 저장되도록 경로를 지정해야 런타임 초기화 후에도 파일을 유지할 수 있다. .keras 파일에는 모델 구조와 가중치 등이 저장되지만, history_aug.history에 담긴 전체 에포크별 기록은 자동으로 보관되지 않는다.

선택: 학습 기록까지 남기려면 pd.DataFrame(history_aug.history).to_csv("cnn_rotation_90_history.csv", index=False)처럼 별도의 CSV 파일로 저장할 수 있다.
