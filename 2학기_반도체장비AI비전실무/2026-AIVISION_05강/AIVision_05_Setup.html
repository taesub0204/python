5. 학습·검증·테스트 데이터셋 준비

훈련·검증 데이터는 동일한 원본 폴더를 시드 42로 나누고, 테스트 데이터는 별도 폴더에서 shuffle=False로 읽는다. 이미지가 다른 파일로 중복되어 있다면 자동으로 중복 내용까지 제거하지는 않는다.

PYTHON · 사전 준비 5

# image_dataset_from_directory를 사용하여 데이터의 크기를 맞춰준다.

# 학습 데이터셋
train_ds = keras.utils.image_dataset_from_directory(
    TRAIN_DIR,
    validation_split=0.2,
    subset="training",

    batch_size=BATCH_SIZE
)

# 검증 데이터셋

)
