Mission 02. 회전 증강 이미지 관찰하기

이미지 데이터 증강과 재현 가능한 실험

학습 목표
  • train_ds에서 이미지 한 장과 정답 라벨을 가져올 수 있다.
  • 같은 이미지에 무작위 회전을 여러 번 적용하여 결과를 시각화할 수 있다.
  • take(), 배치 차원, training=True의 역할을 설명할 수 있다.

1. 실습 준비: 데이터셋과 증강 레이어

Mission 01에서 만든 data_augmentation을 사용하여 실제 웨이퍼맵을 회전시켜 보자. 이번 미션에서는 모델을 학습하지 않고 이미지 변형 결과만 확인한다.

필요한 준비물
  1. 4강에서 생성한 train_ds와 class_names
  2. Mission 01에서 생성한 data_augmentation (±90° 회전, 검은 배경, nearest 보간)
  3. matplotlib.pyplot (이미지 출력)

Colab 런타임을 새로 시작했다면 데이터셋과 증강 레이어를 만드는 셀부터 실행해야 한다.

2. 데이터셋에서 이미지 한 장 가져오기

train_ds는 이미지를 한 장씩이 아니라 배치(batch) 단위로 제공한다. 4강에서 BATCH_SIZE=32로 설정했으므로 일반적으로 한 배치에는 이미지 32장과 대응하는 라벨 32개가 들어 있다.

PYTHON · 배치 하나 살펴보기
# 앞에서 배치 하나 선택
for images, labels in train_ds.take(1):
    print("이미지 배치:", images.shape)
    print("라벨 배치:", labels.shape)

take(n)은 데이터셋의 앞에서 n개 요소를 가져오는 메서드이다. 여기서는 요소 하나가 이미지 한 장이 아니라 배치 하나이므로, take(1)을 순회하는 for문은 한 번 실행된다.

코드선택되는 데이터반복문 실행
take(0)없음0회
take(1)배치 1개1회
take(3)배치 최대 3개최대 3회

이제 가져온 배치에서 첫 번째 이미지와 라벨을 선택하자.

PYTHON · 이미지 한 장 선택
for images, labels in train_ds.take(1):
    # 배치에서 이미지 한 장만 선택
    sample_image = images[0]
    sample_label = labels[0]

print("이미지 형태:", sample_image.shape)
print("정답 클래스:", class_names[int(sample_label)])

sample_image.shape은 (64, 64, 3)으로 출력될 것이다. 높이 64, 너비 64, RGB 채널 3개를 뜻한다.

take(1)의 1은 가져올 배치의 개수이고, images[0]의 0은 배치 안에서 첫 번째 이미지를 가리키는 인덱스이다. 두 숫자의 의미를 구분하자.

3. 이미지에 회전 증강 적용하기

data_augmentation은 keras.Sequential로 만든 객체이다. 함수처럼 호출하면 입력 이미지를 내부 레이어에 순서대로 통과시켜 변형 결과를 반환한다.

PYTHON · 이미지 한 장 회전시키기
augmented = data_augmentation(
    sample_image[None, ...],
    training=True
)

print("변형 결과 형태:", augmented.shape)
표현의미
sample_image[None, ...]이미지 한 장에 배치 차원을 추가: (64,64,3) → (1,64,64,3)
data_augmentation(...)Sequential 객체를 호출해 포함된 RandomRotation 실행
training=True훈련 모드 동작을 활성화하여 무작위 회전 적용

훈련 모드(training mode)는 학습 과정에서만 다르게 작동하는 레이어의 동작을 지정한다. RandomRotation은 훈련 모드에서 이미지를 회전시키고, 추론 모드에서는 회전시키지 않는다.

training=True는 모델을 학습시키라는 명령이 아니다. 실제 가중치 학습은 fit()에서 이루어진다. 현재 증강 레이어에는 학습할 가중치가 없다.

4. 원본과 회전 이미지 6장 출력하기

같은 이미지라도 증강 레이어를 여러 번 호출하면 무작위 회전 각도가 달라질 수 있다. 다음 코드를 작성하여 원본과 증강 이미지를 나란히 비교해 보자.

PYTHON · 원본 1장 + 증강 6장
import matplotlib.pyplot as plt

plt.figure(figsize=(14, 4))

# 원본 이미지
plt.subplot(1, 7, 1)
plt.imshow(sample_image.numpy().astype("uint8"))
plt.title("Original")
plt.axis("off")

# 동일한 이미지를 6번 무작위 회전
for i in range(6):
    augmented = data_augmentation(
        sample_image[None, ...], training=True
    )

    plt.subplot(1, 7, i + 2)
    plt.imshow(augmented[0].numpy().astype("uint8"))
    plt.title(f"Rotation {i + 1}")
    plt.axis("off")

plt.tight_layout()
plt.show()

이 코드는 subplot(1, 7, ...)을 사용하여 1행 7열에 이미지를 배치한다. 회전 결과의 실제 각도는 실행할 때마다 달라질 수 있다.

표시된 결함 유형이 적합한지 판단하기 어려우면, 다른 이미지로 다시 실행하여 비교해도 된다.
