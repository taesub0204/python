실험3. 정보(==특성)을 추가하자!
---> CNN은 이미지만 받아서 여기에 정보추가는 어려움
---> pickle데이터를 다시 사용 --> csv로 변환 후 사용

---> 전처리 > csv로 만들고 저장
---> 전처리 > 특성을 추가함
	* 어떤 특성을 추가할 것인지를 결정해야 함
		: 지금까지의 관찰을 바탕으로 특성을 선택
		: 웨이퍼맵 데이터의 도메인 지식 참고
	* 추가할 특성 결정 
		: 전체 다이의 불량률, 엣지영역의 불량률을 선택
	* 특성을 만들어서 추가하고 csv로 저장.
---> 모델에 입력하기 위한 처리 (정규화)
---> 모델(RandomForest) 학습 / 성능 비교
	* 성능을 비교해볼 대상이 필요함.
	* 비교 대상이 되는 모델 : A (기준 모델, baseline model)
	* A와 비교할 모델 : B (비교 모델)
		-- A와 B를 비교하는 이유
			: 가장 단순하게 만든 모델 A
			: 무언가를 추가한 모델 B
			: 둘을 비교해서 A가 성능이 더 높으면 B를 사용할 이유 없음

		-- 우리 실습의 셋팅
			A모델의 특성 : 불량율
			B모델의 특성 : 불량율, 가장자리(엣지) 불량율

---> 해석 
	-- 이미지로 했을때보다 성능이 좋다
	-- 가장자리 불량율이 성능 향상에 도움이 된다.
	-- 그래도 목표 성능에는 못 미친다. 
	-- 그렇지만, 개선할 방향을 찾았다!!!
		--> 어떤 특성을 추가하면 성능에 도움이 될까?
